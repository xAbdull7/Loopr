# Loopr

**Advanced Discord Quest Automation for BetterDiscord.**

Loopr is a highly optimized, client-side engine designed to seamlessly simulate game activity for Discord Quests. Engineered for stability, it automatically filters out bugged objectives and synchronizes with Discord's internal state using a premium, non-intrusive interface.

## Core Features

* **Dynamic Heads-Up Display:** A minimalist, draggable interface that tracks progress in real-time without cluttering your workspace.
* **Adaptive Titanium Engine:** Automatically detects and filters out bugged or hidden 0-second tasks, locking onto the actual target objective.
* **Smart Synchronization:** Deep integration with Discord's internal modules ensures accurate progress tracking and prevents crashes.
* **Zero-Friction UX:** Replaces intrusive browser alerts with smooth, native in-app notifications.

## Installation

1. Download the `Loopr.plugin.js` file from this repository.
2. Open your Discord client.
3. Navigate to **User Settings** > **Plugins** > **Open Plugin Folder**.
4. Move the downloaded `.plugin.js` file into the opened folder.
5. Enable **Loopr** from the plugins list.
